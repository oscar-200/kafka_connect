# Prueba de Concepto: Transferencia de Datos Oracle → PostgreSQL con Kafka Connect y ksqlDB

Esta prueba de concepto muestra cómo transferir registros de una base de datos **Oracle** hacia **PostgreSQL** usando **Kafka Connect** y normalizar los datos mediante **ksqlDB**.

---

## Requisitos

- Docker y Docker Compose
- Archivos de configuración:
  - `oracle-source.json` → Configuración del conector source de Oracle
  - `sink.json` → Configuración del conector sink hacia PostgreSQL
  - `backup.sql` → Archivo SQL de prueba para insertar datos en Oracle

---

## 1. Levantar los servicios

docker compose up -d --build

Esto levantará los siguientes servicios:

- Oracle DB
- PostgreSQL
- Kafka + Kafka Connect
- ksqlDB Server + CLI

---

## 2. Crear la tabla en Oracle

1. Entrar al contenedor Oracle:

docker exec -it oracle-demo bash

2. Conectarse a la base de datos:

sqlplus system/oracle@//localhost:1521/XEPDB1

3. Crear la tabla `CUSTOMERS`:

CREATE TABLE CUSTOMERS (
  ID NUMBER(38,0) GENERATED BY DEFAULT AS IDENTITY,
  FIRST_NAME VARCHAR2(100),
  LAST_NAME VARCHAR2(100),
  EMAIL VARCHAR2(100),
  PRIMARY KEY (ID)
);
COMMIT;

---

## 3. Crear el conector Source de Oracle

curl -X POST -H "Content-Type: application/json" --data @oracle-source.json http://localhost:8083/connectors

---

## 4. Crear el topic en Kafka

docker compose exec kafka \
  kafka-topics \
  --create \
  --topic oracle-CUSTOMERS \
  --bootstrap-server localhost:9092 \
  --partitions 1 \
  --replication-factor 1

---

## 5. Transformación de datos con ksqlDB

1. Entrar a la CLI de ksqlDB:

docker exec -it ksqldb-cli ksql http://ksqldb-server:8088/

2. Crear los streams:

CREATE STREAM CUSTOMERS_RAW (
    payload VARCHAR
) WITH (
    KAFKA_TOPIC='oracle-CUSTOMERS',
    VALUE_FORMAT='JSON'
);

CREATE STREAM CUSTOMER_EMAILS WITH (
    KAFKA_TOPIC='CUSTOMER_EMAILS',
    VALUE_FORMAT='JSON_SR'
) AS
SELECT
    EXTRACTJSONFIELD(payload, '$.ID') AS customer_id,
    EXTRACTJSONFIELD(payload, '$.EMAIL') AS email
FROM CUSTOMERS_RAW
EMIT CHANGES;

---

## 6. Crear el conector Sink hacia PostgreSQL

curl -X POST -H "Content-Type: application/json" --data @sink.json http://localhost:8083/connectors

---

## 7. Probar la transferencia de datos

1. Entrar a Oracle y ejecutar el backup:

docker exec -it oracle-demo bash
sqlplus sys/oracle@localhost:1521/XEPDB1 as sysdba
@/mnt/storage/backups/backup.sql

2. Verificar los registros en PostgreSQL:

docker compose exec -it postgres-target psql -U postgres -d inventory -c "SELECT COUNT(*) AS total_registros FROM customers;"

---

## Resultado

Si todo está configurado correctamente:

- Los registros de Oracle se publican en Kafka.
- ksqlDB normaliza los datos (ej. `customer_id` y `email`).
- PostgreSQL recibe los datos procesados a través del conector Sink.

---

## Notas

- Asegúrate de que los archivos JSON de los conectores estén correctamente configurados con las credenciales y URLs de tus servicios.
- Puedes monitorear los topics de Kafka usando:

docker compose exec kafka kafka-console-consumer --bootstrap-server localhost:9092 --topic oracle-CUSTOMERS --from-beginning
